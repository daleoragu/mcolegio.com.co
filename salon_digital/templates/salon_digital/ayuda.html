Cómo preparar tu archivo

Si tu actividad guarda resultados, Salón Digital necesita recibirlos en un formato concreto. Hay tres caminos; escoge el que te quede más cómodo.

1 · Descarga una plantilla que ya funciona

Es una prueba completa de tres preguntas, lista para abrir en cualquier editor de texto. Cambia el título y las preguntas, y súbela. El resto ya está resuelto: los datos del estudiante, el avance, el resultado, la revisión al final y el envío.

Si el estudiante se queda sin internet, el resultado se guarda en su celular y se envía solo la próxima vez que abra la página.

Descargar plantilla-prueba.html
2 · Pídesela a una inteligencia artificial

Copia este texto, pégalo en ChatGPT, Claude o Gemini y cámbiale lo que está entre corchetes. Lo que te devuelva se sube tal cual. 

Hazme una página web de una sola pieza, en un archivo .html, con una prueba de
selección múltiple para mis estudiantes.

Tema: [ESCRIBE AQUÍ EL TEMA, por ejemplo: fracciones equivalentes]
Grado: [POR EJEMPLO: quinto]
Cantidad de preguntas: [POR EJEMPLO: 10]

Requisitos de funcionamiento:

1. Todo en UN SOLO archivo .html, sin archivos aparte. El CSS y el JavaScript
   van dentro. Las imágenes, si las hay, incrustadas como data:URI.
2. Debe funcionar en celular y sin internet.
3. Primero pide apellidos, nombres y grupo. Después muestra una pregunta a la
   vez, con cuatro opciones. Al final muestra el puntaje y la revisión de cada
   pregunta con su explicación.
4. Al terminar, envía el resultado a mi plataforma. Para eso incluye EXACTAMENTE
   estas dos constantes, vacías, sin cambiarles el nombre ni el formato:

   const ENDPOINT = '';
   const CLAVE_PANEL = '';

5. Cuando el estudiante termine, arma este objeto y mándalo:

   const RES = {
     ape, nom, completo, sede, gru,
     prueba: 'p1',
     pruebaNombre: 'nombre de la prueba',
     fecha: new Date().toISOString(),
     ok,        // respuestas correctas
     total,     // total de preguntas
     pct,       // porcentaje con un decimal
     seg,       // segundos que tardó
     cambios,   // cuántas veces cambió de opción
     vez: 1,
     det: [
       {
         n: 1,              // número de la pregunta
         apr: 'el aprendizaje que evalúa',
         comp: 'la competencia o eje',
         ac: true,          // si acertó
         marcada: 'B',      // la letra que marcó, o '—' si no respondió
         clave: 'B',        // la letra correcta
         expl: 'la explicación',
         intentos: 1,
         seg: 0
       }
     ]
   };

   fetch(ENDPOINT, {
     method: 'POST',
     headers: { 'Content-Type': 'text/plain;charset=utf-8' },
     body: JSON.stringify(RES)
   });

6. Si ENDPOINT está vacío, no intentes enviar nada y no muestres ningún error.
7. Si el envío falla por falta de internet, guarda el resultado en localStorage
   y reintenta cuando la página vuelva a abrirse.

Las preguntas deben ser contextualizadas y con distractores que correspondan a
errores reales, no opciones absurdas. En la explicación de cada una, di por qué
la correcta es correcta.
3 · Conecta un archivo que ya tienes

Si ya hiciste tu actividad y solo le falta mandar resultados, pega esto antes del </body> y llama a SalonDigital.enviar() cuando el estudiante termine. 

// 1. Las preguntas, con su clave
const preguntas = [
  { id: 1, comp: 'NUM', apr: 'Fracción parte-todo', clave: 'B', expl: '5/20 = 1/4' },
  { id: 2, comp: 'GEO', apr: 'Perímetro',           clave: 'B', expl: '30+15+30+15' },
];

// 2. Lo que marcó el estudiante, en el mismo orden
const marcadas = ['B', 'A'];

// 3. Armar y enviar
const resultado = SalonDigital.armar(preguntas, marcadas, {
  ape: 'Ramos', nom: 'David', gru: '7-01', sede: 'Sede Principal',
  nombrePrueba: 'Prueba de fracciones', segundos: 120,
});

SalonDigital.enviar(resultado).then(function (estado) {
  // 'enviado', 'pendiente' (sin internet) o 'sin-endpoint'
  console.log(estado);
});
Descargar salon.js

El archivo salon.js se pega dentro de una etiqueta <script> de tu HTML. No lo enlaces desde afuera: tu actividad tiene que seguir funcionando sin internet.

Qué pasa cuando subes el archivo
1
Buscamos en tu archivo la línea const ENDPOINT = ''; y la completamos con la dirección de tu actividad. Por eso tiene que estar escrita así.
2
Hacemos lo mismo con const CLAVE_PANEL, poniéndole la clave con la que otros docentes entran a ver los resultados.
3
Revisamos el contenido en busca de señales raras —campos de contraseña, nombres de bancos— y te avisamos si encontramos algo.
4
Queda publicada en tu dirección, con su código QR listo para imprimir.
